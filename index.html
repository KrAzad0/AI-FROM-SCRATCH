AI From Scratch

From silicon to intelligence — an educational journey through the modern AI stack.

General architecture, not proprietary internals.

01 · Silicon

A semiconductor has a band gap. Doping changes carrier concentration; electric fields control carrier transport. CMOS circuits use complementary n-channel and p-channel MOSFETs.

Exercise: Explain how a gate voltage changes channel conductivity.

02 · Transistors

A MOSFET uses an electric field to control current. CMOS inverters connect a pull-up and pull-down network. Switching charges capacitance; dynamic power scales approximately as alpha C V² f.

Exercise: Trace a CMOS inverter for input 0 and 1.

Source chapter
03 · Digital logic

Boolean gates implement arithmetic. A full adder computes sum = a XOR b XOR carry and carry-out = ab OR carry(a XOR b).

Exercise: Construct a four-bit ripple carry adder.

Source chapter
04 · Computer architecture

Instructions are decoded and executed using registers, arithmetic units and caches. DRAM stores larger working sets. Floating-point numbers encode sign, exponent and significand.

Exercise: Compare FP32, FP16 and BF16.

Source chapter
05 · GPUs

GPUs execute many threads and reuse data in registers and shared memory. Tensor units accelerate tiled matrix multiply-accumulate operations. Memory bandwidth often limits decoding.

Exercise: Calculate bytes needed for a billion BF16 weights.

Source chapter
06 · System software

An application calls a numerical runtime, which dispatches kernels through a driver. The operating system manages resources and networking. CUDA and Metal provide different accelerator interfaces.

Exercise: Trace a matrix multiplication from Python to an accelerator.

Source chapter
07 · Programming

Python orchestrates operations; compiled C++ and accelerator kernels do much of the heavy computation. Tensor shapes and memory layout determine valid operations.

Exercise: Implement matrix multiplication using loops.

Source chapter
08 · Mathematics

A linear layer maps x to Wx+b. Softmax normalizes exponentials. The chain rule propagates gradients and probability models assign distributions to tokens.

Exercise: Derive the softmax cross-entropy gradient.

Source chapter
09 · Neural networks

Layers combine affine transformations and nonlinearities. Parameters are learned by minimizing a loss rather than manually storing every answer.

Exercise: Train a scalar linear model with gradient descent.

10 · Tokenization

Byte-pair encoding repeatedly merges frequent adjacent symbols. Token IDs index a vocabulary; tokens need not correspond to words.

Exercise: Implement one frequency-based merge.

Source chapter
11 · Embeddings

An embedding matrix maps IDs to dense vectors. Position information may be encoded using learned embeddings or rotary transformations.

Exercise: Look up two rows of an embedding matrix.

Source chapter
12 · Transformers

Queries, keys and values arise from learned projections. Scaled dot-product attention mixes earlier token representations using a causal mask. Residual connections, normalization and MLPs update representations.

Exercise: Compute a two-token attention matrix by hand.

Source chapter
13 · Training

Next-token training minimizes negative log likelihood. Backpropagation computes gradients; optimizers update parameters. Large runs use distributed computation and checkpointing.

Exercise: Train the included miniature bigram model.

14 · Post-training

Supervised instruction tuning and preference optimization can improve usefulness and instruction following. Evaluation tests capabilities and failure modes.

Exercise: Compare next-token loss with preference objectives.

Source chapter
15 · Reasoning

Some systems spend additional inference computation on intermediate representations or generated working tokens, candidate exploration or verification. Exact proprietary implementations vary. A plausible explanation is not necessarily a faithful internal trace.

Exercise: Compare a direct arithmetic answer with an independently checked solution.

Source chapter
16 · Context and cache

The prompt supplies context. During decoding a KV cache can reuse earlier key and value tensors. Retrieval may insert external evidence; it is distinct from updating model weights.

Exercise: Derive cache storage as 2 L T H D b bytes for batch one.

Source chapter
17 · Tools and agents

An orchestration layer can expose tool schemas, execute permitted calls and return results as context. The model itself does not necessarily execute the external action.

Exercise: Design a calculator tool schema and validate its arguments.

Source chapter
18 · Decoding

Logits become probabilities through softmax. Greedy decoding selects a maximum; temperature and top-p alter sampling. Generation stops on configured conditions.

Exercise: Compare greedy decoding with sampling.

Source chapter
19 · Infrastructure

A request can pass through authentication, routing, batching, prefill, autoregressive decoding and streaming. Tensor and pipeline parallelism distribute work. Exact deployment differs by provider.

Exercise: Distinguish time to first token from inter-token latency.

Source chapter
20 · Build a miniature model

The examples implement a trainable bigram model and a causal attention forward pass. A full GPT adds stacked attention/MLP blocks, residuals, normalization and end-to-end training.

Exercise: Run both demos, then replace the bigram with a trainable transformer.
